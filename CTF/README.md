## About

A collection of my Capture The Flag (CTF) challenge writeups, solutions, practical exercises, and cybersecurity learnings.

This directory documents my approach to solving CTF challenges, including the techniques, tools, findings, and concepts explored during different competitions and platforms.

- Cryptography
- Digital Forensics

- OSINT
- Steganography

## Writeup Structure

Each CTF challenge has its own directory containing:

```text
Challenge-Name/
└── README.md
```

Each writeup may include:

- Challenge overview
- Category and difficulty
- Objectives
- Initial analysis
- Tools and techniques used
- Methodology
- Solution explanation
- Flag discovery
- Key learnings
- References

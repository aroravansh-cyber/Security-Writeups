## Lab Structure

Each experiment or project has its own directory containing:

```text
Lab-Name/
├── README.md
├── screenshots/
└── resources/
```

Each lab writeup may include:

- Project overview
- Objectives
- Lab environment
- Requirements
- Tools and technologies
- Configuration
- Implementation
- Testing and observations
- Results
- Challenges encountered
- Key learnings
- References

## About

A collection of my hands-on machines, challenge walkthroughs, practical exercises, and cybersecurity learnings from **Hack The Box**.

This directory contains my Hack The Box writeups, documenting the methodology, tools, findings, and concepts explored during each machine or challenge.

## Writeup Structure

Each machine or challenge has its own directory containing:

```text
Machine-Name/
└── README.md
```

Each writeup may include:

- Machine overview
- Objectives
- Tools used
- Reconnaissance and enumeration
- Methodology
- Vulnerability analysis
- Findings and analysis
- Key learnings
- References

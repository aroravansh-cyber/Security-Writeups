## About

A collection of my bug bounty learning notes, vulnerability research, authorized security testing, and practical web application security exercises.

This directory documents my approach to identifying, analyzing, validating, and responsibly reporting security vulnerabilities within explicitly authorized scopes.

## Areas Covered

- Web Application Security
- API Security
- OWASP Top 10
- Authentication and Authorization
- Access Control Testing
- Cross-Site Scripting (XSS)
- SQL Injection
- Server-Side Request Forgery (SSRF)
- Security Misconfiguration
- Business Logic Vulnerabilities
- Information Disclosure
- Vulnerability Assessment
- Responsible Disclosure

## Research Structure

Each vulnerability or research topic has its own directory containing:

```text
Research-Name/
└── README.md
```

Each writeup may include:

- Research overview
- Target scope and authorization
- Vulnerability category
- Testing environment
- Methodology
- Technical analysis
- Evidence and observations
- Impact assessment
- Remediation recommendations
- Responsible disclosure status
- Key learnings
- References

## Disclaimer

All security testing documented here is performed within explicitly authorized scopes, controlled labs, or educational environments.

This repository is intended for educational purposes, responsible vulnerability research, and security knowledge sharing.

No unauthorized access, testing, or exploitation is encouraged.
